
# Twilight Hots

A React-based SLIC lookup tool with UPS-themed animation on load.

## 🚀 Features

- UPS logo animation on startup
- Checker to determine if SLIC is HOT or COLD
- Display OB and Load Origin info
- Stylish, modern brown/yellow interface

## 🛠 Getting Started

1. Clone the repo
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm start
   ```

## 📁 Folder Structure

- `public/ups-logo.png` → Logo shown during animation
- `src/App.js` → Main component logic
